GUI layer (QML / EasyApp)
Page per step, right-hand sidebar with Basic / Extra control groups, shared 3D viewer component, editable table component.
Logic layer (Python)
Project, Structure, TaskList, Method, JobRunner and Results objects exposed to QML via QObject proxies. No engine-specific code here.
Engine adapters
One adapter per code: writes input, launches the executable, parses output into a common Results schema. ORCA, PSI4, CASTEP first; interface open for others.
